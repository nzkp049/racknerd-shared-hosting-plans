## 常见问题

**虚拟主机和 VPS 到底怎么选？**

看你需不需要 root。只需要跑 WordPress、企业站、落地页，装插件不改系统，虚拟主机省事得多，cPanel 点几下就上线，安全更新和备份都不用你管，$10.49/年 还比 VPS 便宜。需要装自定义软件、跑 Docker、搭代理或爬虫、改内核参数，那只能上 VPS，$21.99/年 起。

**能装 WordPress 吗？**

能，Softaculous 里一键安装，配 LiteSpeed 加 LSCache 插件，缓存这块不用额外买。注意 30 GB 促销档限 2 个站点，多装一个就要升档。

**支付宝能付款吗？**

能。信用卡、PayPal、支付宝、银联、比特币以及多种加密货币都支持。

**退款怎么算？**

共享主机、分销主机、KVM VPS 都是 3 天退款保障，独立服务器一般不支持。3 天内提交工单申请，别等到第 4 天。

**续费会涨价吗？**

年付促销套餐按官方说明续费价与首购相同。标准月付档按月计价，不存在“续费涨价”这回事，但也没有年付那种折扣。

**站点数或流量不够用了怎么办？**

促销档之间是独立产品，升级一般通过开工单处理，能不能平移剩余时长要以客服答复为准。流量长期接近上限，直接换 85 GB 档更省心。
